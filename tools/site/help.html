Install help

Android won’t let an app install other apps until you allow it once. The switch is called Unknown sources or Install unknown apps, and every brand puts it somewhere slightly different. Find your TV below.

Google TV and Chromecast

  1. Open Settings from the gear at the top right of the home screen.
  2. Go to Apps, then Security & restrictions, then Unknown sources.
  3. Turn on Open Shelf.
  4. Go back to Open Shelf and press Install again.

Sony Bravia

Bravia TVs from 2021 on run Google TV. Use the Google TV steps.

Older Bravia Android TVs: Settings, then Device Preferences, then Security & restrictions, then Unknown sources. Turn on Open Shelf.

Xiaomi Mi Box, Mi TV Stick and Mi TV

Settings, then Device Preferences, then Security & restrictions, then Unknown sources. Turn on Open Shelf.

Newer Xiaomi TVs with Google TV use the Google TV steps. On PatchWall, open Settings from the PatchWall home screen first.

TCL

TCL Google TVs use the Google TV steps. TCL Android TVs: Settings, then Device Preferences, then Security & restrictions, then Unknown sources.

Philips

Settings, then Android settings or Device Preferences, then Security & restrictions, then Unknown sources. Philips Google TVs use the Google TV steps.

Hisense

Only Hisense TVs that run Android TV or Google TV can install apps. VIDAA models can’t run Open Shelf. On Android models, follow the steps for other TVs.

Nvidia Shield

Settings, then Device Preferences, then Security & restrictions, then Unknown sources. Turn on Open Shelf.

Amazon Fire TV

  1. Open Settings, then My Fire TV.
  2. If you don’t see Developer options, open About and press OK on your device’s name 7 times.
  3. Go to Developer options, then Install unknown apps, and turn on Open Shelf.

onn (Walmart)

onn boxes run Google TV. Use the Google TV steps.

Jio, Airtel and Tata Play boxes

Boxes from TV and internet providers often block installs that come from apps. The install screen never appears, and Open Shelf stops after 90 seconds and shows an error.

Look for Unknown sources in Settings first. If it’s missing or does nothing, install apps from a computer instead.

Other Android TVs

Look in Settings for Unknown sources or Install unknown apps. It’s usually in one of these places:

  • Apps, then Security & restrictions (Google TV)
  • Device Preferences, then Security & restrictions (Android TV)
  • Security, or Security & restrictions, near the bottom of Settings

If the switch is greyed out or won’t stay on, an app that draws over the screen may be in the way. Blue light filters and floating buttons do this. Turn them off and try again.

From a computer with adb

  1. On the TV, open Settings, then System, then About (or Device Preferences, then About). Press OK on Build or Android TV OS build 7 times to turn on Developer options.
  2. In Developer options, turn on USB debugging or Network debugging.
  3. Find the TV’s IP address under Network settings.
  4. On the computer, install Android’s platform tools and run:
    adb connect 192.168.1.20 (use your TV’s address)
  5. If Open Shelf’s install switch won’t turn on, allow it from the computer:
    adb shell appops set io.github.wingedpanther.openshelf REQUEST_INSTALL_PACKAGES allow
  6. To install an APK directly:
    adb install app.apk

Google Play Protect warnings

Play Protect sometimes warns about apps that don’t come from the Play Store, Open Shelf included. Choose More details, then Install anyway. Before each install, Open Shelf checks that the file is signed with the same key the developer used before.

Something missing for your TV? Open an issue with the brand and model.
